# Nigerian Pidgin Sentiment Analysis

A Natutal Language Processing project for sentiment classification in Nigerian Pidgin.

## Objective

To develop a machine learning and NLP system capable of classifying Nigerian Pidgin text intro:

- Positive
- Negative
- Neutral
